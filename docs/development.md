## 環境構築

Python 3.12以上とuvを使用します。リポジトリのルートで実行してください。

```console
uv sync --locked
uv run --locked pytest -q
```

`pyproject.toml` と `uv.lock` が依存管理の基準です。`uv sync` がプロジェクトの仮想環境を作成します。実行時依存はなく、開発依存にはpytestとPillowが含まれています。

## 構成

- `src/z_lib/`：ライブラリ本体
- `tests/`：読み取り、編集、パス解決、日本語名、名前空間、拡張子フィルターなどのテスト
- `benchmarks/benchmark_io.py`：一時フォルダでの段階別I/O計測
- `docs/`：利用・開発ガイドと改善候補
- `tasks/done/`：完了した作業の記録。現行仕様の参照先はREADMEとAPIガイド

## 性能計測

```console
uv run --locked python benchmarks/benchmark_io.py --count 1000 --size 1024
```

`--count` は生成ファイル数、`--size` は1ファイルのバイト数です。コピー、展開、読み取り、編集、再圧縮、検証、置換の所要時間を表示します。生成データは一時フォルダ内に作成されます。

このスクリプトは標準ライブラリで処理を再現するもので、Z_LibのAPIを直接測定していません。また「remote」側もローカル一時フォルダのため、Box Driveのネットワーク速度や同期時間の検証にはなりません。

実環境を測定する際は、ファイル数、総展開サイズ、ZIPサイズ、作業領域、同期・キャッシュ状態、測定回数を記録します。フィルターの効果は同じZIPで条件を変えて比較し、取得時間と展開・走査時間を分けて報告してください。
